# Customer Churn Prediction 

This project builds and evaluates predictive models to identify customers at risk of churning. Two supervised learning models were developed and compared: a **Decision Tree** and a **Neural Network**. The goal is to support data‑driven retention strategies by understanding churn drivers and predicting churn likelihood.

---

## Project Overview

- **Dataset:** Telco customer churn dataset (7,043 customers)  
- **Task:** Binary classification — *Churn* vs *No Churn*  
- **Models Trained and Evaluated:**  
  - Decision Tree 
  - Neural Network   
- **Evaluation:** Metrics computed on a held‑out test set of 1,407 instances
